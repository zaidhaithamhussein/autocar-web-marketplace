# AutoCar

A car marketplace built with PHP, MySQL, HTML, CSS and JavaScript. Users can sign up, sign in, list their own cars with a photo, and edit or delete their listings.

## Setup

1. Create a MySQL database and import `schema.sql`.
2. Copy `config.example.php` to `config.php` and fill in your database details.
3. Serve the folder with PHP (for example `php -S localhost:8000`).

## Features

- Sign up and sign in with hashed passwords
- Add, edit and delete your own car listings
- Image upload (JPEG/PNG, up to 2 MB)
- Home page carousel of the latest listings
- Responsive layout with automatic light and dark mode
